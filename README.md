# dsh-theme-endfield

> 《明日方舟：终末地》风格的 DSH Web 界面皮肤插件。
> 信号黄侧栏 + 顶部黄带 + 平涂底 + 地形等高线，聊天面为弧形面，带一段官方站点式的开屏动画；
> 主背景有**浅色（默认）与深色**两套变体，用「设置 → 通用 → 外观」即可实时切换。

## 它改了什么

| 维度 | 做法 |
|---|---|
| **主背景（深/浅两版）** | 同一套色阶出两个变体：**浅色**（默认，纸白 `#f2f2f0` 底 + 墨色 `#131312` 字）与**深色**（灰黑底 + 纸白字）。浅色不是另写一套配色，而是把两条中性色阶**整条镜像**，于是深色模式的别名映射自然落在「浅底深字」上，信号黄/校验绿/警示橙等语义色原样保留；两套表面合成**一层令牌**（每个令牌带 `light`/`dark` 两个槽），主题服务按当前激活主题的取色方案选槽，所以**设置 → 通用 → 外观**切浅/深时皮肤立刻跟着换、且不需要重新注册令牌层。样式表里写死的那几处（结构线、等高线、外框、角标、面板、输入框、气泡、焦点环、开屏）由 `html[data-endfield-surface="light"]` 一节覆盖 |
| 配色 | 重写 DSH 的整套 `--dsw-static-*` 色阶（中性灰阶 `#1a1a1a` 起 + 信号黄 + 校验绿），因此所有组件——侧栏、会话、工具卡、设置、代码块、菜单——一起换色，而不是逐个改样式 |
| **黄栏** | 侧栏以信号黄为主：该作用域内把文字／边框／交互令牌整体反绑为墨色，子元素读 `var()` 时自然变深色；黄底上的选中条同步反相成墨色，`新会话` 去掉外圈描边、只留文字与图标 |
| **左上角圆角** | 侧栏黄色面板的左上角是 **76px 正圆角**（`border-top-left-radius`，凸向角、圆心在黄块内侧的四分之一圆，不是"从角上挖掉一个圆"的凹口）。画法：外层 `sidebarCol` 铺主背景色、内层根容器铺黄色并加圆角，切掉的那块自然露出外层颜色；两层都**不用伪元素、不加定位、不建层叠上下文**。半径是量出来的上限——圆弧在字标图标左缘处只有 ≈25px 高，正好从图标上方擦过，所以**不需要移动任何内容** |
| **面板与弹窗** | 深色变体的面板层级整体抬高（`#232321 / #2a2a28 / #333330`，否则和 `#131312` 底色只差几个百分点、糊成一团黑），模态遮罩 62%→50%；浅色变体的弹窗是**纯白面 + 墨色描边 + 实投影**。另外，设置弹窗的 DOM 其实落在侧栏子树里，会继承黄栏那套「墨色标签」反相——所以在 `[role="dialog"]` 上把页面级文字/边框/交互令牌按变体显式恢复回来（深色纸白字、浅色墨字） |
| **输入光标** | 深色变体沿用品牌黄；浅色变体下默认的白光标在纸白输入框上看不见，改成深暗金 `#6f6a00`（`caret-color`，纸白底上对比度约 5.5:1） |
| **顶部黄带** | 黄色直接画在会话头部自己的 `background-color` 上（内容自然压在黄之上、不会被蒙住），从侧栏平滑漫过 `对话 / 轨迹` 那一行；黄带内所有文字与图标同步转为墨色，页签只留一条笔直的墨色横线 |
| **圆角过渡** | 侧栏与顶带交汇的内角补一块 34px 四分之一圆（concave fillet），并向上多盖 16px 实色黄吃掉接缝，所以圆弧与黄带之间没有空隙；位置按运行时量到的侧栏宽 / 头部高动态对齐，侧栏拖动、切换会话都会跟上 |
| 强调色 | 品牌色在普通区域仍是信号黄 `#fffa00`：主按钮、激活会话条、进度与链接；在黄栏／黄带内自动反相成墨色。聊天框周边**没有任何黄色线条**（浅色变体下发送键是墨色圆钮、深色变体下是纸白圆钮） |
| **几何（圆弧）** | 全站 `corner-shape: round` + 大圆角：控件 10px、面板/对话框 16px、视口外框 14px；不再用 45° 削角 |
| **聊天面** | 输入框与用户气泡改成弧形（输入框 20px、气泡 22px）：浅色变体是纸白面板 + 墨字，深色变体是比底面亮一档的浅灰 `#3a3a3a → #313131`；输入区内按钮与芯片变圆形／胶囊，框边没有任何黄色线条 |
| **等高线** | 确定性地形等高线场：6 处「山头」各自 6–10 圈谐波等高线；普通线 `1.7px`，每 5 条一条**计曲线**加粗到 `2.4px`（真实地图的索引等高线规则：深色变体用信号黄、浅色变体用更深的 `rgb(122 108 0 / 72%)` 以免在纸白底上看不见；开屏那块场为 `1.5px`/`2.1px`）。主界面里贴视口四周 + 两处落在画面内，径向遮罩只把中间压淡（不抹掉），120s 极慢漂移；开屏里以字标所在山头为中心**逐圈绘制出来** |
| **平涂底面** | 底色是不带任何条纹／网格／辉光的纯色（浅色 `#f2f2f0` / 深色 `#131312`）；背景上只留等高线一层纹理，再加一片极浅的四周压暗 |
| 排版 | 界面系统无衬线 + `Cascadia Mono` 数据字体；数字等宽对齐（`tabular-nums`）；品牌字标大写加字距；表头大写微标签 |
| 外框 | 1px 视口外框 + 四角括号（深色变体：左上角落在暗角用信号黄、左下角落在黄块用墨色；浅色变体：全部改用墨色），呼吸动画遵循 `prefers-reduced-motion` |
| 开屏动画 | **跟随表面变体**（浅色：纸白装载屏 + 墨色等高线与文字；深色：原灰黑装载屏）。平涂装载屏：等高线自绘 + 标定线扫过 + 四角依次扣上 + 字标横向遮罩揭示 + 底部等宽读表与五格活动指示；就绪后黄幕**从右上角一条约十分之一屏宽的窄柱竖直落下 → 整块向左滑动铺满全屏 → 从右往左渐变溶解露出界面**（溶解作用在整层上，所以不会闪回装载屏）。全部文案都是真实信息（界面自己的标语、启动清单的构建号与模块数） |
| **调色模式锁定** | 皮肤不写「外观」偏好，只把**调色模式属性**钉在深色：`body` 上始终带 `data-ds-dark-theme`（DOM 断言 + `MutationObserver` 兜底），因为整套色阶是照着深色模式的别名映射写的；表面明暗由变体决定，变体跟随偏好与 `color-scheme` 覆盖 |

设计语言细节与令牌映射见 [docs/design-language.md](docs/design-language.md)。

## 安装
```powershell
# 本机路径安装
dsh plugin --profile web add link:E:\dsh\dsh-theme-endfield

# 从 npm 安装（发布后）
dsh plugin --profile web add dsh-theme-endfield

# 卸载
dsh plugin --profile web remove dsh-theme-endfield
```

`dsh plugin add` 会把这个包写进 `~/.dsh/profiles/web/package.json` 的依赖，并因为包内声明了
`dsh.bundle.patch` 而自动追加到 `dsh.profile.bundles` 层栈——重启 `dsh web` 后自动挂载，
无需手改配置。

> 本机当前还额外在 `~/.dsh/profiles/web/cordis.patch.yml`（用户补丁层，`patchReload: live`）
> 中挂了一行**热挂载条目**（id 为 `theme-endfield-hot`，指向同一个包）。它的作用是让
> **正在运行**的 `dsh web` 进程立刻加载皮肤，而不用重启——重复的条目 id 会让启动直接失败，
> 所以这一行刻意用了不同的 id；同一个包被挂两次时，浏览器端模块图按包名去重，
> 不会出现两张皮肤。
>
> 想要更干净的配置：删掉那段 `insert` 即可（运行中的进程会卸载皮肤，下次启动由
> 包自带的 bundle patch 重新挂载）。**不删也不影响启动**，已验证。

生效方式：刷新浏览器页面（`http://127.0.0.1:3080`）即可。

## 开关与调试

| 用途 | 方式 |
|---|---|
| **切换主背景深/浅** | **设置 → 通用 → 外观**（浅色 / 深色 / 跟随系统），选完立刻生效、无需刷新；皮肤按该偏好切换表面变体 |
| 绕过偏好钉死某一版 | 控制台 `localStorage.setItem('dsh-endfield-surface','dark')`（或 `'light'`）后刷新；也可用地址栏 `?endfield=dark-surface` / `?endfield=light-surface` |
| 临时关闭皮肤 | 地址栏加 `?endfield=off`，或控制台执行 `localStorage.setItem('dsh-endfield','off')` 后刷新 |
| 只关开屏动画 | 地址栏加 `?endfield=splash-off`，或 `localStorage.setItem('dsh-endfield-splash','off')` 后刷新 |
| 重播开屏动画 | 控制台执行 `__dshEndfield.splash()` |
| 恢复皮肤 | `localStorage.removeItem('dsh-endfield')` 后刷新 |
| 查看当前变体 | 控制台 `__dshEndfield.surface()`（返回 `light` / `dark`） |
| 查看主题状态 | 控制台 `__dshEndfield.snapshot()`（当前偏好、激活主题、令牌表） |
| 手动切换偏好 | 控制台 `__dshEndfield.set('light')`（等同于点设置里的外观，皮肤会跟着换） |

> 地址栏参数在**首次带 token 打开**时会被登录跳转丢掉（跳转到干净的 `/`），
> 所以想钉死某一版请用 `localStorage` 那条。

开屏动画的行为：任意点击 / 按键 / 滚轮即刻跳到黄色擦除；系统开启“减少动态效果”时整段动画跳过；
界面渲染完成前不会提前结束，最长等待 6 秒；动画结束即把整个层从 DOM 移除，不留常驻节点。

## 目录结构
```
dsh-theme-endfield/
├─ package.json          # dsh.bundle.patch + dsh.client 声明
├─ cordis.patch.yml      # 把 theme-endfield 行插进 profile 配置树
├─ lib/
│  ├─ index.js           # Host 半边：往 index.html 注入“开机即深色”引导脚本（消除白屏闪烁）
│  └─ client.js          # 浏览器半边（构建产物，已提交，安装即用）
├─ src/
│  ├─ palette.js         # 色阶重写 + 语义别名覆写（令牌层）
│  ├─ endfield.css       # 皮肤样式表（几何、排版、质感、外框、开屏动画）
│  └─ plugin.js          # 客户端插件主体（注入样式、外框、开屏动画、锁定深色）
└─ scripts/build.mjs     # 把 src/* 内联成 lib/client.js（零依赖）
```

## 开发

```powershell
cd E:\dsh\dsh-theme-endfield
node scripts/build.mjs      # 修改 src/ 后重新生成 lib/client.js
```

`lib/client.js` 是 DSH 客户端模块系统的注册门面
（`window.__ModuleLoader__.load({ id, factory })`），必须由构建脚本生成，不要手改。
插件刻意**不 require 任何共享模块**（只用 DOM 与 `ctx.theme`），因此不会因为外部模块缺失而加载失败。

改完 `lib/client.js` 后无需重启：DSH 的 client-hmr 行会轮询客户端产物并广播 `rebuilt`，
浏览器端热替换，或刷新页面即可。

## 已知限制

- **只做深色**：浅色偏好会被忽略（DOM 层面的深色断言）。用着眼睛难受就没做了
- **会写一次 `dark` 偏好**：插件首次加载时把 `ui-theme.preference` 写成 `dark`，让设置面板显示一致；之后不再改写（避免与其它浏览器的设置作用域互相打架）。
- **选择器与 DSH 版本耦合**：少量规则依赖 DSH 现有的 DOM 钩子（`data-composer-card`、`data-*` 以及 `_sessionRow` / `_panelActive` 这类 CSS Module 类名片段）。DSH 大版本升级后若某些细节失效，改 `src/endfield.css` 对应小节即可。
- **45° 削角需要 Chromium 139+**（`corner-shape`）。Firefox/Safari 下优雅回退为普通圆角，配色与结构不受影响。
- 未做浅色版、未替换图标与字体文件（不引入网络字体，离线可用）。

## 兼容性

针对 `@deepseek-ai/dsh@0.1.5-rc.1` / web profile 开发与验证；Host 半边只依赖
`webserver/index-inject` 这一个稳定事件，客户端半边只依赖 `ctx.theme`（ui-theme 的令牌覆写层）。
